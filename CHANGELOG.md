# Changelog

## 2.2.0 — 2026-08-30

- Модель «база простая — PRO вся мощь»: мощные твики убраны из бесплатной версии и переехали в раздел PRO
- Производительность: Ultimate Performance, парковка ядер, Turbo Boost, таймеры и приоритеты, DPC, память, GPU, Nagle — только в PRO
- Раздел «Ядро / VBS» убран из бесплатной версии
- Кнопка «Оптимизация» в один клик теперь применяет только обычные безопасные настройки
- Возле премиум-настроек значок PRO; без лицензии при попытке применить показывается сообщение, что доступно только бесплатное

## 2.1.0 — 2026-08-30

- Лицензия **PRO**: офлайн-ключ (подпись Ed25519), раздел «PRO» в приложении
- Новые PRO-твики: UAC полностью OFF, Prefetch + Superfetch OFF, авторемонт (DISM restorehealth + SFC), отключение EPP, PRO Мега-пакет (8 оптимизаций одной кнопкой)
- Кнопка «Купить PRO» и активация ключа прямо в приложении
- Покупка через Telegram-бота продавца (@ottorpf_bot), оплата криптой или FunPay

## 2.0.0 — 2026-08-30

- Полностью новый интерфейс на WebView2
- Твики Windows 10 и Windows 11: CPU, RAM, GPU, сеть, диск, приватность, глубокий пак для Windows 10
- Бенчмарк процессора, памяти и диска
- Мониторинг температуры и нагрузки в реальном времени
- Работа в системном трее, сворачивание по крестику
- Discord Rich Presence с динамическими статусами
- Создание точки восстановления перед изменениями
- История применённых твиков и откат
- Экспорт и импорт настроек
- Автообновление через GitHub с уведомлением в приложении
- Кнопка «Исключить в Windows Defender»
- Портативный один файл .exe — без установки и Python
