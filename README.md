# KALASH TWEAKER


![KALASH TWEAKER](https://pupsik-yamakasi.github.io/KalashTweaker/screenshot.png)

Бесплатная утилита для оптимизации Windows 10 и Windows 11: оптимизация системы в два клика, твики, бенчмарк, мониторинг, работа в трее и Discord Rich Presence.

## Возможности

- Оптимизация и твики Windows (CPU, RAM, GPU, сеть, диск, приватность)
- Бенчмарк процессора, памяти и диска
- Мониторинг температуры и нагрузки в реальном времени
- Сворачивается в трей и не мешает играм
- Discord Rich Presence — статус в твоём профиле
- История изменений и откат твиков
- Экспорт и импорт настроек
- Автообновление и кнопка «Исключить в Windows Defender»
- Все твики открыты бесплатно, без лицензий: умная оптимизация, Ultimate Performance, парковка ядер, таймеры и приоритеты, память, GPU, сеть, ядро, UAC OFF, авторемонт DISM+SFC, Мега-пакет
- Портативная: один exe, Python не нужен, установка не требуется
