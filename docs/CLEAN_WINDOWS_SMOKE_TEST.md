# Проверка релиза на чистой Windows

Используйте отдельную виртуальную машину Windows 10 или Windows 11. Не выполняйте опасные твики на основном компьютере.

1. Создайте снимок VM и установите только WebView2 Runtime, если его нет.
2. Скопируйте `KALASH_TWEAKER_v2.exe`; сверяйте его SHA-256 с опубликованным хешем.
3. Запустите приложение от обычного пользователя и от администратора. Проверьте старт, значок в трее, скрытие окна и повторный запуск.
4. Проверьте интерфейс: загрузку категорий, системную информацию, настройки, историю, экспорт и импорт настроек.
5. На тестовой VM примените один безопасный реестровый твик. Убедитесь, что создана точка восстановления и файл резервной копии реестра.
6. Проверьте откат твика и восстановление из резервной копии реестра.
7. Создайте ежедневную, еженедельную и ежемесячную задачу автоочистки; проверьте их через `schtasks /query /tn KALASH_TWEAKER_AutoCleanup`.
8. Проверьте обновление только на тестовом релизе с `SHA256SUMS`; приложение должно отказаться скачивать EXE без корректного хеша.
9. Проверьте, что опасные действия требуют ввода `KALASH` и точки восстановления.
10. После теста откатите снимок VM.
